# 第1章：スクレイピング不要！日本政府公式オープンデータ3種が最強のAI情報源である理由

企業調査・与信確認・営業リスト精査・投資分析をAIエージェントに任せようとすると、多くの開発者が最初に「企業サイトやポータルサイトをスクレイピングする」アプローチを思い浮かべます。

しかし、第三者サイトへの無断スクレイピングには致命的な弱点があります。

- 利用規約違反・IPブロック・CAPTCHAによる継続不能
- HTML構造変更による頻繁なメンテナンス地獄
- 情報の一次根拠が曖昧で、AIのハルシネーションを検証しにくい

一方、日本政府が公開している一次オープンデータAPIを組み合わせれば、**利用規約の範囲内で商用加工・再配布まで合法的に行え、しかも公式の13桁法人番号をキーに完全な名寄せが可能**です。

## 本書で横断統合する3つの公式ソース

| ソース | 提供元 | 取得できる一次データ | 商用加工・再配布 |
| --- | --- | --- | --- |
| **法人番号公表仕様** | 国税庁 | 13桁法人番号の公式チェックデジット検証 | 可（出典記載） |
| **gBizINFO API v1** | 経済産業省 | 法人基本情報、資本金、従業員数、代表者、補助金・調達情報 | 可（出典記載） |
| **EDINET API v2** | 金融庁 | 有価証券報告書・大量保有報告書などの法定開示書類一覧 | 可（出典記載） |
